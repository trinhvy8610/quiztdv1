Cách lưu dự án & Đưa QuizTDV lên web

1Cách lưu dự án về máy (Backup)

Vì toàn bộ mã nguồn của trang web này nằm gọn trong **1 file HTML duy nhất**, bạn chỉ cần nhấn nút **Preview** hoặc chuột phải ở code editor -> Chọn lưu hoặc copy toàn bộ nội dung code dán vào một file mới đặt tên là index.html trên máy tính là bạn đã lưu xong toàn bộ dự án.

2Cách đưa lên web MIỄN PHÍ để mọi người cùng dùng (GitHub Pages / Vercel)

  • Bước 1: Đăng ký tài khoản miễn phí trên GitHub.com.
  • Bước 2: Tạo một Repository mới (kho chứa code) dạng công khai (Public).
  • Bước 3: Tải file index.html của ứng dụng lên Repository đó.
  • Bước 4: Vào phần Settings của Repository -> Chọn mục Pages -> Ở phần Build and deployment, chọn nguồn là Deploy from a branch (main) rồi nhấn Save.
  • Chỉ sau 1 phút, GitHub sẽ cấp cho bạn một đường link web chính thức (ví dụ: https://tenban.github.io/ten-repo). Bạn có thể gửi link này cho bất kỳ ai để vào ôn tập và tạo học phần!
